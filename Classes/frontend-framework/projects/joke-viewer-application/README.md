# Random Joke Generator 😂

A simple React app that fetches and displays random jokes using the FreeAPI Random Joke API.

## Features

* Fetches random jokes from an API
* Displays one joke at a time
* "New Joke" button to load another random joke
* Loading and error handling
* Built with React Hooks
* Beginner-friendly project

---

## Tech Stack

* React
* JavaScript
* Vite
* Fetch API
