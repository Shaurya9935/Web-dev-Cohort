# Meals Listing Interface

## Project Overview

This project is a Meals/Recipes Listing Interface built using React and Tailwind CSS.
The application fetches meal data from the Meals API and displays meals in a clean and structured interface.

Users can browse meals, click on any meal card, and view detailed information including:

* Meal image
* Meal name
* Category
* Area/Cuisine
* Instructions
* Tags
* Ingredients with measurements
* YouTube tutorial link

The project focuses on API handling, dynamic rendering, conditional rendering, and responsive UI design.

---

## Technologies Used

* React.js
* JavaScript (ES6+)
* Tailwind CSS
* Meals API
* Fetch API
* React Hooks (`useState`, `useEffect`)

---

## API Used

API Endpoint:

https://api.freeapi.app/api/v1/public/meals

---

## Features

* Fetches meals dynamically from API
* Displays meals in card layout
* Click on meal card to view details
* Dynamic ingredients and measurements table
* Loading and error state handling
* Clean UI using Tailwind CSS
* AbortController used for cleanup in API calls

---

## Project Structure

* `App.jsx` → Main application logic
* `useEffect` → API fetching
* `useState` → State management
* Tailwind classes used for styling and layout
