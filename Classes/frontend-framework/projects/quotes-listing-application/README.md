# Random Quote Generator ✨

A simple React app that fetches and displays random inspirational quotes using the FreeAPI Quotes API.

## Features

* Fetches random quotes from an API
* Displays one quote at a time
* "New Quote" button to load another random quote
* Loading and error handling
* Built with React Hooks
* Beginner-friendly project

---

## Tech Stack

* React
* JavaScript
* Vite
* Fetch API
* Tailwind CSS
